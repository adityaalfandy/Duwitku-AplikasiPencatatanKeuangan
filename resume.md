# Lanjutkan pekerjaan

1. Baca `docs/06_PROGRESS.md` saja terlebih dulu. Jangan membaca seluruh `docs/`.
2. Tentukan sub-task berikutnya (atau yang kusebut setelah perintah ini) dari `docs/05_TASKS_MILESTONES.md` bagian "Pecahan sub-task".
3. Baca HANYA dokumen yang tercantum di "Peta dokumen per sub-task" pada `AGENTS.md`.
4. Periksa kondisi kode dengan membuka file terkait saja, jangan memindai seluruh proyek.
5. Kerjakan sub-task itu saja, dengan edit seperlunya (jangan menulis ulang file utuh).
6. Build sekali di akhir. Perbaiki error bila ada.
7. Perbarui `docs/06_PROGRESS.md` (status, titik berhenti, keputusan, file yang berubah).
8. Balas singkat: apa yang selesai, cara mengujinya, dan sub-task berikutnya. Jangan commit.
